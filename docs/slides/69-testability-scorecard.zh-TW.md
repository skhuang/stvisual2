# 可測試性計分卡
### *五個訊號、一次診斷、一個等第*

軟體測試視覺化系列 #69 · 可測試性計分卡
搭配工具：`?explorer=testability-scorecard` → 可測試性計分卡（[TestabilityScorecardExplorer](../../src/components/TestabilityScorecardExplorer.js)）

<!-- 可測試性章節的收尾講。計分卡是總結：它不推導任何新東西——它把三個姊妹探索器（可控制性／可觀察性、接縫、結構度量）加上非確定性目錄組合成五個正規化訊號，取平均得出單一 A–F 等第，並把最低的訊號轉成一份有優先序、可深連結的修復清單。本講走過聚合方式、確切的固定裝置讀數、等第門檻、修復連鎖，以及計分卡如何驅動「為可測試性而設計」的工作。 -->

## 總結 — 從眾多訊號得出單一診斷

本章節先前每一講各自孤立地教一個可測試性性質：測試能否*驅動*程式碼（可控制性）、能否*看見*結果（可觀察性）、能否*替換*相依（接縫）、結構有多*糾纏*（度量），以及執行是否*可重現*（非確定性）。

計分卡是**總結**。它回答那些講次留下的問題：*把這些全部同時擺在一起，這個單元有多可測試——而我該先修什麼？*

關鍵在於，它**不重新推導任何東西**。它在一份共享的固定裝置上組合姊妹探索器的純引擎，把每一個正規化成同一尺度上的訊號，再取平均得到單一總體等第。一個真理來源、五個讀數、一個數字。

<!-- 要建立的框架：計分卡是聚合器，不是新的分析。強調「組合，不重新推導」——controllability() 與 observability() 來自可控制性／可觀察性探索器，testabilityOf() 來自接縫探索器，testabilityHardness() 來自度量探索器，而非確定性計數來自固定裝置。它增添的價值是單一可比較的診斷加上一份有優先序的工作清單。與孤立的講次對比：每一講都是對某一性質的顯微鏡；這一講是俯瞰全部五者的儀表板。 -->

## 五個訊號

計分卡讀取恰好**五個**訊號，每一個都正規化到 `[0, 1]`，其中**越高 = 越可測試**：

- **可控制性**——測試能把受測系統*驅動*進入的狀態比例。
- **可觀察性**——測試能從外部*分辨*的狀態比例。
- **接縫覆蓋**——被注入接縫所打破的相依反模式比例。
- **結構**——最難的單元離最壞情況硬度上限還差多遠。
- **確定性**——已被移除的非確定性來源比例。

把每一個性質都放到同一條 `0..1、越高越好` 的軸上，正是讓它們**可比較**的原因——可控制性 0.6 與確定性 0.5 現在能坐在同一個排名中，而尋找「最弱環節」也就變成一次單純的排序。

<!-- 列舉五者，更重要的是正規化慣例。有些訊號天生就是比例（可控制性、可觀察性、接縫覆蓋）；另外兩個被轉成比例：結構是 1 − 最難/上限，所以低複雜度模組得高分；確定性是 1 − 現存/總數，所以移除一個非確定性來源就把它拉高。共享的單一尺度是整個訣竅——它讓算術平均與「最低訊號」排名在以不同單位衡量的性質之間仍然有意義。 -->

---

## 正規化 — 越高 = 越可測試

有兩個訊號不是天生的比例，因此計分卡把它們換算：

- **結構** `= clamp(1 − 最難 / 25, 0, 1)`。`testabilityHardness()` 為最難的單元評分；`25` 是最壞情況上限（`STRUCT_CAP`）。結構單純的模組得分接近 1；固定裝置最難的單元得 19，於是 **1 − 19/25 = 0.24**。
- **確定性** `= clamp(1 − 現存 / 4, 0, 1)`。`4` 是非確定性來源的完整目錄（`DET_TOTAL`）。移除一個來源，訊號就上升；現存 4 個中的 2 個，於是 **1 − 2/4 = 0.5**。

符號慣例是刻意且一致的：**越可測試永遠是越大的數字**。複雜度與非確定性是稅，所以以 `1 − 稅` 的形式進入，讓它們與各比例保持在同一條「向上為好」的軸上。

<!-- 這是讓數字可重現的投影片。把兩條公式寫在黑板上並代入固定裝置：最難 = 19、上限 = 25 → 0.24；現存 = 2、總數 = 4 → 0.5。強調反轉——原始的結構與非確定性度量「高時為壞」，所以在取平均之前被翻成「高時為好」。少了統一的方向，平均就會把蘋果加到反蘋果上。 -->

## 固定裝置讀數

隨附的固定裝置——一個投幣旋轉柵門 SUT、一個電商結帳模組、尚未套用任何接縫、沒有探針、兩個非確定性來源——評分結果為：

| 訊號 | 分數 | 來自何處 |
|---|---|---|
| 可控制性 | **0.6** | 測試能驅動進入的狀態 |
| 可觀察性 | **0.2** | 能從外部分辨的狀態 |
| 接縫覆蓋 | **0** | 尚未注入任何反模式接縫 |
| 結構 | **0.24** | 1 − 19/25 |
| 確定性 | **0.5** | 1 − 2/4 |

總體 = 平均 = (0.6 + 0.2 + 0 + 0.24 + 0.5) / 5 = **0.308** → 等第 **F**。

<!-- 逐列走過表格，然後是算術平均。每一個數字都是精確的，直接來自固定裝置與引擎——可控制性 0.6 與可觀察性 0.2 來自柵門的可達／可分辨狀態，接縫 0 是因為 appliedSeams 一開始為空，結構 0.24 與確定性 0.5 來自上一張投影片的公式。平均 0.308 是總體；徽章顯示 31%。強調這裡的 F 是*誠實的起點*——固定裝置刻意設計成不可測試，好讓修復有進步的空間。 -->

## 等第門檻

總體（平均）分數對應到一個字母等第，由**高到低**檢查：

| 等第 | 總體 ≥ |
|---|---|
| A | 0.85 |
| B | 0.70 |
| C | 0.55 |
| D | 0.40 |
| F | 其餘 |

在 **0.308** 時，固定裝置低於 D 的門檻 0.40，所以落在 **F**。等第是一個粗略、一眼可見的摘要；底下的逐訊號長條才是真正的診斷所在。

<!-- 門檻就是 GRADE_THRESHOLDS 表格的原文；由上往下檢查，總體越過的第一個 min 勝出。指出單一極弱訊號可以透過平均把整個等第壓低——這裡接縫 0 與可觀察性 0.2 把 0.308 拖到遠低於 0.40 的 D 線之下。等第是頭條；訊號長條才是內文。這為優先序鋪路：要移動等第，就移動最低的長條。 -->

## 優先處理最低的訊號

單一等第告訴你*有多糟*，而非*該做什麼*。所以計分卡把訊號**依分數遞增排序**（平手時以固定的訊號順序決勝），並把**最低的三個**呈現為一份有優先序的修復清單。

對於固定裝置，最低的三個是：

1. **接縫覆蓋 — 0** → 注入一個接縫（可測試性接縫探索器）
2. **可觀察性 — 0.2** → 加一個輸出探針（可控制性與可觀察性探索器）
3. **結構 — 0.24** → 拆解那個協調者（可測試性度量探索器）

先修最弱的環節：因為等第是平均，把一個 `0` 或 `0.2` 拉高，對總體的推動遠大於打磨一個已經很高的訊號。

## 修復連鎖

有些修復會**同時**移動不止一個訊號——計分卡透過在你切換修復時即時重新評分，把這點變得可見。

- **注入時鐘接縫與亂數接縫。** 每一個都注入一個接縫（拉高**接縫覆蓋**）*並且*移除一個非確定性來源（把**確定性**拉向 1）。兩個訊號一起上升，總體越過 0.40：**F → D**。
- **注入全部四個接縫**（設定、閘道、時鐘、亂數）。接縫覆蓋達到 **1.0**，確定性已經是 **1.0**，總體越過 0.55：**F → C**。

這就是計分卡的核心課題：槓桿最高的修復，是*單一*設計變更讓**多個**訊號能共享的那些。

<!-- 在工具中即時演示連鎖。inject-clock 與 inject-rng 各自身兼二職：接縫被加入 appliedSeams（接縫覆蓋 0 → 四個中的兩個為 0.5），而對應的來源被從 nondeterminism 濾除（確定性 0.5 → 1.0）。總體變成 (0.6+0.2+0.5+0.24+1.0)/5 = 0.508 → D。打開全部四個接縫，接縫覆蓋為 1.0：(0.6+0.2+1.0+0.24+1.0)/5 = 0.608 → C。要帶走的重點是槓桿——一個注入接縫的習慣在兩個訊號上同時見效，這正是值得優先的那種設計變更。 -->

## 每個訊號都連回它的老師

計分卡是一個**樞紐**，不是死路。優先清單中的每一項修復都帶著一個深連結，指向教那個訊號的探索器——於是一次診斷就變成一條通往修復它的課程的引導路徑：

| 訊號 | 連到 |
|---|---|
| 可控制性 | 可控制性與可觀察性 |
| 可觀察性 | 可控制性與可觀察性 |
| 接縫覆蓋 | 可測試性接縫 |
| 結構 | 可測試性度量 |
| 確定性 | **不穩定診斷**（非確定性 → 不穩定測試） |

所以一個低確定性分數不只是說「你有非確定性」——它把不穩定測試探索器交到你手上，該探索器展示*為什麼*一個未固定的時鐘或亂數會讓測試變得不穩定，以及接縫如何移除它。

<!-- 這些是 SIGNAL_META 的深連結。值得特別點出的是確定性 → flaky-diagnosis：非確定性是不穩定測試背後的機制，所以計分卡把一個弱的確定性訊號導向直接教不穩定性的探索器。設計要點：總結講收合了迴圈——它回報的每一個弱點，都離教那個修復的工具只差一次點擊，把整個章節從五堂各自獨立的課變成一個可導航的診斷系統。 -->

## 驅動「為可測試性而設計」的工作

從頭到尾讀下來，計分卡把「讓這個更可測試」從一個模糊的願望，變成一個**可衡量的迴圈**：

1. **評分**這個單元——得到一個誠實的數字與五根長條。
2. **排序**——最低的三個訊號就是工作清單，最糟者優先。
3. **修復**——跟隨每一個深連結，套用接縫／探針／拆解。
4. **重新評分**——看著連鎖抬高多個訊號、等第爬升。

固定裝置的旅程——**F（0.308）** → 注入時鐘 + 亂數 → **D** → 全部四個接縫 → **C**——正是這個迴圈的縮影。為可測試性而設計不再是口耳相傳的傳說，而變成一塊你能撥動的計分板。

<!-- 在此收束章節。計分卡真正的產物不是等第，而是那個迴圈：衡量、排序、修復、再衡量。追蹤固定裝置的弧線 F → D → C，作為迴圈確實能移動數字的證明。連結到實務：在真實程式碼上，把這五個訊號接進 CI，計分卡就成為一份可測試性預算——一道在變更使等第下降時失敗的閘門，以及一份告訴團隊哪一個設計變更買到最多可測試性的工作清單。 -->

## 小結

- **計分卡是可測試性章節的總結**：它**組合**三個姊妹探索器加上非確定性目錄成為一次診斷，且**不重新推導任何東西**。
- **五個訊號**，每一個都正規化到 `[0, 1]`，**越高 = 越可測試**：可控制性、可觀察性、接縫覆蓋、結構、確定性。
- **結構 = 1 − 19/25 = 0.24**、**確定性 = 1 − 2/4 = 0.5**——複雜度與非確定性以 `1 − 稅` 的形式進入，讓「向上為好」一致成立。
- **固定裝置讀數**為可控制性 0.6、可觀察性 0.2、接縫 0、結構 0.24、確定性 0.5 → 總體 **0.308** → 等第 **F**。
- **等第**把平均由高到低對應：A ≥ 0.85、B ≥ 0.70、C ≥ 0.55、D ≥ 0.40，其餘為 F。
- **優先處理最低的**三個訊號（接縫 0、可觀察性 0.2、結構 0.24）；平均獎勵抬高地板。
- **修復連鎖**：注入時鐘 + 亂數同時拉高接縫覆蓋*與*確定性 → **F → D**；注入全部四個接縫 → **C**。每個訊號都深連結到它的探索器，其中確定性 → 不穩定診斷。

**課堂練習：** 從 F 固定裝置出發，列出用最少修復抵達等第 C 的切換順序，並為每一次切換點名它移動的每一個訊號以及移動了多少。
